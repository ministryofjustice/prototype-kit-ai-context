# AI Context for GOV.UK Prototype Kit

A comprehensive AI context document designed to assist with developing prototypes using the GOV.UK Prototype Kit.

## Overview

This repository contains guidance and best practices for building government service prototypes, including:

- Core concepts and patterns
- Component usage and implementation
- Design system integration
- Common patterns and page layouts
- Accessibility guidelines
- Testing and validation approaches

## Contents

- **ai-context.md** — The main AI context document with detailed guidance on using the GOV.UK Prototype Kit

## About

This AI context is maintained by the Ministry of Justice to provide clear, structured guidance for developing prototypes that comply with UK government standards and the GOV.UK Design System.
